#USING DOTS IN MATHEMATICAL STATEMENTS: e.g. matrix with diagonal dots

\ldots - Low dots, sitting on the baseline. Use them between commas — lists and sequences.

\cdots - Centered dots, raised to the middle of the line. Use them between operators such as + or =.

\vdots - Vertical dots. Continues a column downward.

\ddots - Diagonal dots. Continues a leading diagonal down and to the right.


\hdotsfor{n} - Fills n columns of a matrix row with dots (needs amsmath). Handy for omitting a whole row. Example output can be seen below:

(a b c) #assume that this ia  a 2x3 matrix

#THEOREMS, DEFINITIONS, AND REMARKS: use \usepackage{amsthm}:
In the preamble:

\newtheorem{environment name}{heading text} - Use as many \newtheorem declarations as you like — lemma, corollary, definition, example, remark — and each will  have its own counter number.

environment name -  the environment name you'll type to begin that structure.  This name is not predefined for you and can be a full word (lemma) or abbreviation (lem).  
You decide on the term that you'll want to type throughout your document.


heading text - the heading word that appears in the document

Basically, you are creating your own command:

\newtheorem{theorem}{Theorem}
\newtheorem{lemma}{Lemma}
\newtheorem{corollary}{Corollary}

\begin{document}

\begin{theorem}


\end{theorem}


\end{document}
